# When Does Contiguity Help Watermark Detection?

Project page for the Stat 236 (Fall 2026) final project by Elvin Lo, Gianfranco Randazzo, Bryan Fang and Evan Ho.

- `index.html`: the page (Nerfies-style layout; Bulma, Font Awesome and KaTeX load from cdnjs).
- `static/images/`: figures, copied from `../figures/`.
- `static/pdfs/paper.pdf`: the report.
- `.nojekyll`: tells GitHub Pages to serve the files as they are.

## Publishing on GitHub Pages
This folder is served from the `docs/` folder of the repository.
1. In the repository, open Settings → Pages. Under "Build and deployment", choose "Deploy from a branch", then `main` and `/docs`.
2. The page appears at https://elvinlo.github.io/watermark-text-detection/ a minute or two after each push.

## Updating
After changing the paper or figures, copy the new `paper.pdf` to `static/pdfs/paper.pdf` and any changed figures to `static/images/`, then push.
