# When Does Contiguity Help Watermark Detection?

**Sharp Phase Diagrams for Segment-Surviving Gumbel-max Watermarks**

Elvin Lo, Gianfranco Randazzo, Bryan Fang, Evan Ho. Stat 236 (Fall 2026) final project, Harvard University.

Project page: https://elvinlo.github.io/watermark-text-detection/
Paper: [`docs/static/pdfs/paper.pdf`](docs/static/pdfs/paper.pdf)

## Contents
| Folder | Contents |
|---|---|
| `code/` | Simulation library, experiments E1–E5 and theory figures. See [`code/README.md`](code/README.md) for which script produces each figure and table. |
| `figures/` | Figures and raw power estimates (`.json`) written by the scripts in `code/`. |
| `docs/` | The project page, served by GitHub Pages. |

## Reproducing
Requires Python 3.9+ with `numpy`, `scipy` and `matplotlib`. Run the commands in `code/README.md` from inside `code/`; outputs go to `figures/`.
